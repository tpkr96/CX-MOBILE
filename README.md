# Crypto Terminal Mobile

Phone app (installable web app) of the crypto trading terminal. Paper trading only: it never asks for an API key and never places orders.

Open the GitHub Pages link on your phone, then tap **Install app** (Android) or Share → Add to Home Screen (iPhone).

Built from `stocks/v6` by `stocks/mobile/build/build_mobile.py` in the project files.

## India Bot (NSE + BSE)

Open https://tpkr96.github.io/CX-MOBILE/india/ for the Indian-market paper bot on Dhan's live feed. See `india/README.md`.
